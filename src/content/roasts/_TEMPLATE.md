playbook: |
  **Phase landmarks (bean temps — NOT your Behmor B-temp).** The Behmor's A/B
  readout is chamber temp and self-limits ~310–314°F; it is *not* bean temp. Use
  these to know what each event *is*; roast by the events + ~300°F band, not the numbers.

  | Transition | Bean temp | Cue |
  | --- | --- | --- |
  | Dry end | ~150°C / 300°F | green→yellow, hay→bread, ~5–6 min |
  | First crack | ~196–205°C / 385–401°F | sustained rhythmic popping, ~10–11 min |
  | Second crack | ~220°C / 428°F | faster sharper crackles (Medium-dark drop = first snaps) |

  Drop temp by level (bean °F): Light ~405–415 · Medium ~425–435 · Medium-dark ~435–445.

  1. Weigh 227 g green into drum. Empty chaff tray.
  2. Preheat (first roast only): drum OUT, 1 lb + any profile, START, run 1:30, cancel. Skip for back-to-back.
  3. Insert drum. Select P5 / ½ lb, START. Phone timer running.
  4. Chopstick in door slot around 7 min.
  5. 75% SHUTOFF: press START when display counts down 0:30 or machine auto-cools.
  6. Dry end (~5–6 min): yellow + hay→bread (bean ~300°F). Listen for FC (bean ~385–401°F); mark time-to-FC.
  7. Drop at target window (bean temp per level above). Hit C.
  8. Cool ~10 min. Weigh roasted.
